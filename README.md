# Rhode Island Computer Museum — Website Redesign

A redesign prototype for [ricomputermuseum.org](https://www.ricomputermuseum.org), built as a
single self-contained HTML file (`site.html`) — embedded CSS design system + client-side JS that
renders each page (Home, Visit, Learn, Mission, Collections, etc.) into `#main`.

## Design system

The visual language (palette, type, spacing) is drawn from Section 5 of the RICM Website Design
& Experience Specification, which is the source-of-truth over any earlier mockup image where the
two disagree. Fonts: **Sora** (display) + **Inter** (body/UI), with **IBM Plex Mono** used
sparingly for object IDs / specs / session codes — a restrained nod to computing heritage, never
for interface text. Fixed light-content / deep-navy-chrome museum identity — a deliberate
single-theme brand commitment, not an omission.
